GitHubを、フォルダー操作に近い感覚で扱うWindows用アプリ「GitHug」の初回配布です。無料で利用できます。

### ダウンロードと起動

**`GitHug-1.0.0-Windows-x64.zip` をダウンロード**し、すべて展開して `GitHug/GitHug.exe` を開いてください。Pythonは不要です。

GitHubが自動表示する「Source code」はソースコード用です。アプリを使う場合は上記のWindows版ZIPを選んでください。

### 主な機能

- 履歴を選び、毎回新しいフォルダーに再現
- 差分を確認して同じ場所へ更新。更新前の保管と手元だけのファイルの保持を選択
- 送る変更を選び、GitHubの新しい枝や更新可能な枝へ送信
- 履歴の分岐グラフ、検索、ページ切り替え、自分用メモ
- フォルダーツリー、VS Code・PowerShell起動
- 任意のGemini説明。送信前の確認、APIキーを保存しない接続設定

Windows 11 x64向け。Gitを同梱しています。送信や非公開プロジェクトにはPC側のGitHub認証が必要です。

### 確認内容

84件のテスト、Windowsでの配布EXEの起動・追加パネル・同梱Gitの確認、Defenderでの配布フォルダーとZIPの検査を通過したビルドを掲載します。
`GitHug-1.0.0-Windows-x64.sha256` はZIPのSHA-256です。

コード署名は付けていません。環境によって警告が出る場合があります。
submodule・Git LFSの実体取得、競合編集、Python実行環境の準備は対象外です。

[使い方・注意点](https://github.com/ISUKA-SSP/GitHug#readme)
