# GitTotte v1.1.0

GitHugから **GitTotte** に改名しました。GitHubに「取っ手」を付ける、Windows用の無料アプリです。

## まずは「操作ガイド」から

やりたいことを選ぶと、実際の画面を操作しながら進められます。次に操作する場所を水色の枠で示し、選択済みの手順は省略します。コピー・記録・送信などが成功すると案内が完了します。AIやAPIキーは不要です。

## 主な更新

- 操作名／Git用語のその場での表示切替。
- PCだけに記録を残し、後から確認・GitHubへの送信。
- PCとGitHubの両方で更新されたファイルを、PC側／GitHub側／保留から選んで確認。
- 作業ルート同士の比較と、GitHubでの取り込み提案への案内。
- PCの記録・更新前バックアップから、毎回新しいフォルダーへ復元。メモも引き継ぎ。
- PC一覧のCtrl・Shift複数選択、ごみ箱への移動、見つからない項目だけの整理。
- 下側に開くPowerShellパネル。複数行コマンド・途中の入力・中断・終了。
- 検索欄の整理、選択が見やすい配色、説明表示、動くキャラクター。

## ダウンロード

`GitTotte-1.1.0-Windows-x64.zip` をすべて展開し、`GitTotte` フォルダー内の **GitTotte.exe** を開いてください。Windows 11・64bit向け。Pythonは不要で、公開プロジェクト取得用のGitも同梱しています。

**「Source code (zip)」は実行ファイル入りのWindows版ではありません。** Windows版は上記の名前の添付ファイルを選んでください。

GitHubへの送信・非公開プロジェクトには、PC側の認証と権限が必要です。ChatGPTのGitHub接続は引き継ぎません。

## 旧版からの更新

旧アプリを終了し、新しいZIPを別の場所へ展開して起動します。既存の登録フォルダー・自分用メモ・設定・保存済みAPIキーは引き継ぎます。互換性のため、設定保存先は引き続き `%APPDATA%\GitHug` です。

## 確認について

Windowsで184件のテスト、配布EXEの起動・主要画面・同梱Git・PowerShellの確認、Defenderによる配布フォルダーとZIPの検査を実施するビルドから公開します。コード署名はありません。ChromeやWindowsの判定は利用環境によって異なります。
