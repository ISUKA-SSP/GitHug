# 目的から進む操作ガイド

上部の「操作ガイド」から開きます。Gitの用語を知らなくても、次の目的から選べます。

- GitHubのファイルをPCで使う：新しいフォルダーへコピー／登録済みフォルダーを更新
- PCで編集した内容を残す：PCだけに記録／GitHubへ送信
- ファイルの違いを確認：履歴とPC／作業ルート同士を比較
- 別の作業ルートの変更を取り込む：比較からGitHubでの提案作成へ
- 前の状態を取り出す：GitHubの履歴／PCの記録／更新前バックアップ

ガイド自体は選択や処理を勝手に始めません。主画面の選択を使い、次に操作する場所を水色の枠で示します。すでに選べた手順は省きます。ドラッグでも案内内のボタンでも進められます。

戻る・閉じるで案内を離れられます。閉じても完了済みの操作は取り消しません。進行中の処理もガイドを閉じただけでは中断しません。通常の確認画面が開いている場合は、その画面のキャンセルで主画面へ戻れます。

コピーや送信などの成功を確認して完了にします。失敗・中止・別のプロジェクトの処理・以前の案内の処理で完了にしません。ルート比較の案内完了は「比較結果が開いた」ことです。提案・合流の完了を自動判定しません。最新版は利用したいルートの先頭を利用者が選び、別ルートの新しい日時を最新版として自動選択しません。

設定やAPIキーは不要です。今回もPython版のみです。
