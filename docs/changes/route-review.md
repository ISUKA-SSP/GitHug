# GitTotte 1.1.0a10：作業ルートを比較して取り込み提案へ

1. 履歴の下の「比べる・取り込む」から「別の作業ルートと比較・取り込み提案」を選びます。履歴の右クリックにも同じ入口があります。
2. 左に取り込み元、右に取り込み先を選択。取り込み元 → 取り込み先の向きで比較します。先は通常mainなどの本流です。
3. 共通の出発点から取り込み元への変更をファイル一覧で表示。ファイルを選ぶと、その差分だけを読み込みます。
4. 「GitHubで取り込み提案へ進む」を押すと、履歴を取り直して比較時の先端と一致するか確認します。更新・削除されていれば再比較を案内。
5. 確認後にブラウザーでGitHubの作成／比較ページを開きます。比較ページが開いた場合は「Create pull request」から作成に進めます。ブラウザーのログインと権限を使用します。
6. 作成前にGitHubでも元・先と差分を確認し、提案の作成・確認・合流を行います。GitTotteのボタンだけでは提案を送信せず、合流もしません。APIキーの追加は不要です。
7. GitHubで作成・合流した後はGitTotteの履歴を更新してください。ブラウザーでの作成完了をアプリが自動判定することはありません。

- この段階は同じGitHubプロジェクト内の作業ルート同士が対象。別プロジェクト・フォークをまたぐ比較や、アプリ内での合流確定は対象外です。
- 同じルートは比較できません。追加履歴が既に取り込み先に含まれる場合や共通の出発点がない場合は、提案へ進むボタンを無効にします。
- 両側で更新されている場合も、自動で上書き・合流しません。変更がぶつかるかどうかの最終確認はGitHubで行います。
- 選択変更・ウィンドウを閉じた後に古い処理結果が届いても、以前の内容で提案ボタンを有効化しません。
- 作業フォルダー・PCの記録・GitHub上の履歴は比較だけでは変更しません。
- 操作名／Git用語をその場で切り替えられます。実際のルート名やファイル名は書き換えません。
- 今回もPython版のみです。
