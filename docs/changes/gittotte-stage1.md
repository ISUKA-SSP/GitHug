# GitTotte 1.1.0a7：改名と表示用語

- メイン画面・使い方・起動コマンド・今後の配布名をGitTotteへ変更。
- `python -m gittotte` で起動。従来の `python -m githug` も互換入口として維持。
- 設定の保存先 `%APPDATA%\GitHug`、資格情報の識別子、既存のメモ・登録フォルダー・管理ファイルの形式は維持。データの移動・削除はしません。
- メイン画面の「表示用語：操作名／Git用語」で即時切替。既定は操作名。設定を保存し、次回起動にも反映。
- 「作業ルート／ブランチ」「記録して送る／コミットしてプッシュ」「履歴の更新／フェッチ」など、対応する操作だけを切替。別フォルダーへのコピーはプルと呼びません。
- 開いているメニュー・見出し・選択肢・操作説明にも適用。ユーザーが入力した文章、履歴の原文、メモ、ファイル名・ルート名、LLM回答、ターミナル出力は書き換えません。
- 上側のPowerShellボタンを削除。PCのフォルダー側のボタンから下部パネルを操作。
- 停止・着席・考え中・起き上がり・転倒でも最後に歩いた向きを維持。移動範囲の端では、次の歩行方向と表示方向を分けて管理。
- 開発中はPythonのテストとWindowsでのソースGUI確認のみを自動実行。EXEビルドは手動実行へ変更。起動部分を公式ソースからビルドする方式は今後の配布にも維持。

## 実機確認

```powershell
python -m pip install -r requirements.txt
python -m gittotte
```

表示用語を切り替え、入力や選択が保持されることを確認してください。PCへコピーの名称は変わりません。右上のキャラが左へ歩いた後、その向きで止まり・座ることも確認できます。

本段階ではコミットのみの保存・合流・衝突解決・復旧機能の追加は行いません。次の段階で個別に検討・実装します。
