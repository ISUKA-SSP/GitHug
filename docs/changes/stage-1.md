# ① 言葉と画面の整理（1.1.0a1 試用版）

- 「再現」を「コピー」に統一。コピー操作・フォルダーの表示・ドラッグ中の案内を揃えました。
- 更新の対象を明記し、バックアップや編集内容を取り消す操作の説明を整理しました。
- 履歴とPCフォルダーの検索欄を、それぞれ見出しと同じ行に配置しました。×またはEscで検索を解除できます。
- 空いた高さを一覧に割り当てました。

通常のウィンドウ幅と説明パネルを開いた状態で、検索欄・件数・一覧が見えることをご確認ください。履歴の検索、PCフォルダーの検索、×での解除、上下ドラッグの案内も確認対象です。

コピー・更新・送信の処理方式は従来通りです。この段階は画面と表記の整理です。
