# GitTotte 1.1.0a8：PCのフォルダーをまとめて整理

- Ctrlで選択を追加・解除、Shiftで範囲選択。余白からドラッグして囲む選択は追加しません。
- 選択済みの行の右クリックは複数選択を維持。選択していない行を右クリックすると、その行だけが対象になります。
- 「フォルダーをごみ箱へ移動」は存在する安全な対象だけを処理。見つからない項目はそのまま一覧に残ります。移動した項目も記録とメモを維持します。
- 「見つからない項目を一覧から取り除く」は存在しない対象だけを処理。存在する項目は残し、移動先のファイルやメモには触れません。
- 実行前に全対象と対象外の理由・件数を確認。多い場合はスクロール付き確認画面を使用。キャンセルが既定です。
- 対象とプロジェクトは確認時に固定し、各フォルダーの状態を実行時にも再検証。失敗しても残りを続け、最後に個別の結果を表示。
- 親子のフォルダーを同時に選択した場合は、その両方を対象外にして一方だけを選ぶよう案内。重複した保存場所は一度だけ扱います。
- PowerShellが使用中のフォルダー、管理領域・アプリ本体・保護フォルダー・リンクなどの既存の削除制限を維持。完全削除への切替はありません。
- 複数選択中のドラッグ送信は行わず、1フォルダーを選ぶよう案内。送信・編集・PowerShell・更新など単一対象の操作も先頭の1件を勝手に扱いません。
- 再表示・検索・並べ替えの際は、一覧番号ではなく保存場所で選択を保持。

Python版のみで確認し、EXEは作成しません。
