# ② 操作ガイドと設定（1.1.0a2 試用版）

- 主要ボタン、検索欄、履歴とPCフォルダーにマウスを重ねると説明が出ます。約0.65秒後に表示し、4.5秒後、クリック、マウスを離す操作で消えます。
- 上部の「設定」で、マウスの説明と左側の操作案内をそれぞれON/OFFにできます。設定は次回起動にも引き継ぎます。
- 履歴を選ぶと下へコピーする操作、PCフォルダーを選ぶと上へ送信する操作を左側に案内します。
- Geminiの接続設定から、APIキーを任意でWindowsの資格情報マネージャーへ保存できます。設定JSONには保存しません。初期状態は保存OFFです。保存済みの場合は次回起動で読み込みます。チェックを外して適用するか、「保存済みキーを削除」で削除できます。削除ボタンは即時に反映します。
- 分岐の説明では比較の出発点を候補から選択できます。比較しないときやファイルを選んだときは、この欄を隠します。

確認：マウスの説明の表示・自動消去・設定OFF、選択時の案内、設定の再起動後の維持、APIキーの保存・再起動・削除。保存を希望しない場合はチェックを付けずにご利用ください。
