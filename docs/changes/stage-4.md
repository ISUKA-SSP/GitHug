# ④ ステラとシリカのアニメーション（1.1.0a5 試用版）

- 右上の二人が、待機中にまばたき・歩行・着席・立ち上がりを行います。動く範囲は専用の小さな枠内だけです。
- 履歴取得、比較や説明の準備・依頼中は考える姿に、コピー・更新・送信・ごみ箱への移動中は段ボールを運ぶ姿に変わります。
- 処理でエラーが起きたときは、一人が一度だけ転び、起き上がります。失敗状態のまま転び続けることはありません。
- 処理が重なった場合は、ファイル操作中の表示を優先します。キャラの動きで進捗の割合を表すものではありません。
- キャラクターをクリックすると「使い方・環境」を開きます。そこからLivingAgentの紹介・配布ページへ進めます。クリックだけで外部ページは開きません。
- 「設定」の「キャラクターを動かす」をOFFにすると従来の座った静止画へ戻り、アニメーションのタイマーも停止します。案内を開くクリックは引き続き使えます。設定は次回起動にも引き継ぎます。

キャラ表示のための通信やLLMの呼び出しは行いません。PowerShell内で実行した任意のコマンドの内容も判定しません。GitHugが管理している操作の開始・完了・エラーに合わせた表示です。

提供された素材から、Tkが直接読み込める小さなPNGスプライトを作成しています。ランタイムの追加ライブラリは不要です。元の素材の名前・SHA256は `githug/assets/mascots/sprites.json`、再作成用の手順は `tools/build_mascot_sprites.py` を参照してください（再作成時だけPillowが必要です）。
