# GitTotte 1.1.0a9：PCだけに記録する

- PCのフォルダーの右クリックに「PCに記録だけ残す」を追加。ファイルと説明・名前・メールを確認し、選択した変更をローカルコミットに保存します。
- 通常の送信確認画面にも「PCに記録だけ残す」を追加。「記録してGitHubへ送る」と分け、記録だけの場合は送信先の入力を求めません。
- PCだけへの記録では、履歴が初回取得済みならGitHubとの通信は不要。作業フォルダーとそのGit履歴は変更しません。
- 記録は管理フォルダーの local-records 以下の独立したGitコピーに保存。GitHub履歴のミラーの削除・整理で失われる参照には依存しません。
- 同じ作業フォルダーの続きは前のPCの記録から比較・記録。フォルダーが置き換えられたり比較元が変わったときは以前の記録を勝手に基準にしません。
- 上部の「保管した内容」から「PCの記録」「更新前のバックアップ」を選択。PCの記録はGitHubの履歴とは別に表示します。
- PCの記録から変更を確認し、後から保存済みのコミット自体を送信できます。保存後に編集したファイルや、削除した元フォルダーには依存しません。
- 以前のPCの記録も送信に含まれる場合は、まとめた差分を確認してから送信。既存ルートの履歴を巻き戻したり、分かれた変更を上書きしたりしません。
- 名前とメールはPCの記録に含まれます。後からGitHubへ送れば公開されます。削除は記録内のファイルにだけ反映します。
- 記録した内容の復元操作は、後続の復旧機能の段階で追加します。本段階は記録・差分確認・後からの送信までを扱います。

```powershell
python -m pip install -r requirements.txt
python -m gittotte
```
