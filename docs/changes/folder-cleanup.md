# PCのフォルダー一覧の整理（1.1.0a4 試用版）

- 利用できるフォルダーを右クリックし「フォルダーをごみ箱へ移動」でPC上の実物を移動できます。作業用フォルダーは確認文に明記し、場所とファイル・手元の編集も含むことを確認します。
- ごみ箱へ移した後は、記録を一覧に残します。同じ履歴からコピーし直すことも、記録を取り除くこともできます。
- 「削除または移動されています」の項目には「一覧から取り除く（ファイルは削除しません）」を表示します。GitHubの履歴、自分用メモ、作成元の記録、移動先の実物は削除しません。
- アプリ本体、ドライブ全体、プロジェクト全体や管理用データ、リンクを経由する場所は削除対象にできません。対象フォルダーのPowerShellが動いている場合は先に終了してください。
- ごみ箱への移動にはWindows Shellを使います。完全削除への自動切り替えは行いません。ネットワーク・取り外し可能なドライブなど、ごみ箱を確実に使えない場所はこの操作の対象外です。
