# 記録・バックアップを新しいフォルダーへ復元

「保管した内容」からPCの記録または更新前バックアップを選び、「新しいフォルダーへ復元」を押します。ファイル数・サイズ・新しい保存場所を確認してから開始します。

- PCの記録：その記録に保存した変更と元のファイルを取り出します。記録しなかった手元だけのファイルは含みません。
- 更新前バックアップ：バックアップに入っている設定・手元だけのファイル・空フォルダーも取り出します。
- 毎回新しいフォルダーを作ります。元のフォルダーや記録、バックアップを上書き・削除しません。復元したプログラムも自動実行しません。
- PCの一覧に出どころと復元日時を残し、元のフォルダーの自分用メモを引き継ぎます。上書き更新はOFFから始まります。
- PCの記録から取り出したフォルダーは、その記録を引き継いで次の記録を保存できます。
- 復元したフォルダーが後から見つからなくなった場合、元の記録から再び新しいフォルダーへ復元できます。復元後に加えた未記録の変更は戻りません。

キャンセル時は復元を開始しません。途中で失敗した場合は作成途中のコピーだけを片づけ、元のデータを残します。危険なパスやリンク、Windowsで重複する名前は展開前に拒否します。

今回はPython版のみです。
