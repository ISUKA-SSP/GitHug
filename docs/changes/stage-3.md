# ③ 埋め込みPowerShell（1.1.0a3 試用版）

PCのフォルダーを選び「PowerShell／コマンド」で開きます。上部の「PowerShell」で表示を切り替えられます。

- 下側に一時的なパネルを重ねます。隠すと元の一覧配置へ戻ります。パネル上端をドラッグして高さを変えられます。
- 右のコマンド欄へ複数行を貼り、「コマンドを実行」またはCtrl+Enterで実行します。
- `Read-Host`やPythonの`input()`など、途中の質問には「途中の入力」から答えます。Enterまたは「入力を送信」で送信し、空欄のEnterも送れます。
- 「処理を中断」はCtrl+Cを送ります。応答しない場合は「終了」でPowerShellと、その画面から起動した処理を終了します。
- ✖は表示を隠すだけです。処理・入力待ちは続き、再度開くと同じセッションへ戻ります。
- プロジェクトや選択項目を変えても開始場所は変わりません。別のフォルダーで開く際は、今のセッションを終了する確認を出します。1つのセッションを扱います。`cd`した後の現在位置はPowerShellのプロンプトで確認してください。
- 出力を選んでCtrl+Cでコピーできます。選択なしのCtrl+Cは中断です。出力を遡っている間は自動で末尾へ飛ばず、「最新の出力へ」で戻れます。最大1500行のスクロール履歴を保持します。
- GitHugを閉じる際にもPowerShellの終了を確認します。プロセスの所有権はWindowsのJob Objectで管理し、子プロセスも一緒に終了します。

コマンド本文を受け渡す一時ファイルは読み込んだ直後に削除し、セッションの終了時にも片付けます。設定ファイルにコマンドを保存しません。PowerShellはプロファイルを読み込まずに起動します。画面・色の再現は基本的な文字表示を対象とし、全画面型のエディターなどは外部のターミナルをご利用ください。

ソース版は起動前に `python -m pip install -r requirements.txt` を実行してください。Windows ZIP版には必要な部品を同梱します。
